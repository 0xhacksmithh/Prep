# 1️⃣ What is TypeScript?

**TypeScript is a strongly typed superset of JavaScript developed by Microsoft.**
It adds static typing and other advanced language features on top of JavaScript and then compiles (transpiles) into plain JavaScript that browsers and Node.js can run.

**Key Points:**

- Every valid JavaScript code is valid TypeScript

- TypeScript code is not executed directly

- It is compiled into JavaScript using the TypeScript Compiler (tsc)

**Example:**

```c
let age: number = 25;
```

➡ Compiles to:

```c
let age = 25;
```

**Why it exists:**

JavaScript is flexible but error-prone in large codebases. TypeScript adds predictability and safety.

# 2️⃣ Why use TypeScript instead of JavaScript?

TypeScript solves scalability and maintainability problems of JavaScript.

✅ **Static Typing**

Detects errors before runtime.

```c
let count: number = "10"; // ❌ Error
```

✅ **Better IDE Support**

- Autocomplete

- Go to definition

- Refactoring

- Inline documentation

✅ **Compile-time Error Detection**

```c
function add(a: number, b: number) {
  return a + b;
}
add(2, "3"); // ❌ Error
```

✅ **Better for Large Projects**

- Self-documenting code

- Easier onboarding

- Safer refactoring

- Fewer runtime bugs

📌 **Most enterprise apps** (Angular, NestJS, large React apps) use TypeScript

# 3️⃣ Is TypeScript interpreted or compiled?

TypeScript is compiled (transpiled).

**Compilation Flow:**

```c
TypeScript (.ts)
      ↓ tsc
JavaScript (.js)
      ↓
Executed by Browser / Node.js
```

**Tool Used:**

```c
tsc index.ts
```

**Important:**

- TypeScript does not run in the browser

- Types are removed during compilation

- Runtime has no TypeScript types

# 4️⃣ What are TypeScript’s main features?

### 🔹 1. Static Typing

Types are checked at compile time.

```c
let price: number = 100;
```

### 🔹 2. Interfaces

Define object structure.

```c
interface User {
  id: number;
  name: string;
}
```

### 🔹 3. Generics

Reusable, type-safe components.

```c
function identity<T>(value: T): T {
  return value;
}
```

### 🔹 4. Enums

Named constants.

```c
enum Role {
  Admin,
  User,
}
```

### 🔹 5. Decorators (Experimental)

Used in frameworks like Angular & NestJS.

```c
@Controller()
class UserController {}
```

### 🔹 6. Type Inference

Automatically infers types.

```c
let x = 10; // number
```

### 5️⃣ What are primitive types in TypeScript?

Primitive types represent single immutable values.

```c
string      // text
number      // integers & floats
boolean     // true / false
null        // intentional absence of value
undefined   // unassigned
symbol      // unique identifiers
bigint      // large integers
```

**Example:**

```c
let name: string = "Alice";
let isActive: boolean = true;
```

📌 Same as JavaScript primitives, but with type safety.

# 6️⃣ What is type inference?

TypeScript automatically determines the type of a variable based on its value.

**Example:**

```c
let x = 10;
```

TypeScript infers:

```c
let x: number
```

Why it’s important:

- Less boilerplate

- Cleaner code

- Still type-safe

📌 You don’t need to write types everywhere.

# 7️⃣ What is any type?

The `any` type disables TypeScript’s type checking completely.

```c
let value: any = "hello";
value = 10;
value = true;
value.toUpperCase(); // No error ❌
```

**Problems with any:**

- Loses all type safety

- Defeats purpose of TypeScript

- Causes runtime bugs

**When it’s used:**

- Migrating JS → TS (temporary)

- Third-party libraries (rare)

⚠️ Avoid using any in production code

# 8️⃣ What is unknown type?

`unknown` is a safe alternative to `any`.

```c
let val: unknown;
val = 10;
```

❌ Not allowed:

```c
val.toFixed(); // Error
```

✅ Allowed after type check:

```c
if (typeof val === "number") {
  val.toFixed();
}
```

**Why `unknown` is better:**

- Forces type checking

- Prevents unsafe operations

- Improves reliability

# 9️⃣ Difference between any and unknown

| Feature            | `any`     | `unknown`        |
| ------------------ | --------- | ---------------- |
| Type checking      | ❌ No     | ✅ Required      |
| Safety             | ❌ Unsafe | ✅ Safe          |
| Operations allowed | Anything  | After validation |
| Recommended        | ❌ No     | ✅ Yes           |

**Interview Tip:**

“Use unknown when you don’t know the type yet but still want safety.”

# 🔟 What is void?

`void` represents absence of a return value.

**Example:**

```c
function logMessage(message: string): void {
  console.log(message);
}
```

**Key Points:**

- Function returns nothing

- Common in logging, event handlers, side effects

- Different from never

📌 `void` = function completes execution
📌 `never` = function never completes
